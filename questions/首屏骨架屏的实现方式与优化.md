## 答案 1：核心简洁的口语化回答

・手动编写 HTML/CSS 模拟页面结构，用灰色块占位内容区域，通过动画实现加载感。

・利用 Webpack 等构建工具自动生成骨架屏，注入 HTML 并设置显示时机。

・骨架屏需与实际页面布局一致，通过 CSS 控制在内容加载完成后隐藏。

・可配合预加载技术，在 HTML 头部加载骨架屏，减少白屏时间。

・复杂场景可使用 SVG 或图片作为骨架屏，降低渲染成本。

## 答案 2：口语化扩展回答

实现首屏骨架屏主要是为了在内容加载时展示一个近似最终页面的灰色占位布局，让用户感觉页面在加载而不是卡住。最简单的方式是手动写一段 HTML 和 CSS，用灰色块和线条模拟标题、图片、文字等元素，再加点轻微的动画效果，让用户知道页面正在准备中。

在实际项目里，更多会用构建工具自动生成，比如 Webpack 插件可以分析页面结构，自动生成对应的骨架屏代码，然后注入到 HTML 里。关键是要控制好骨架屏的显示和隐藏时机，通常是在 DOM 加载完成或数据请求返回后，用 JS 把骨架屏替换掉。

骨架屏要尽量和真实页面布局一致，不然加载完成后会有明显的跳变感。对于性能要求高的场景，可以用 SVG 或者图片做骨架屏，加载更快。现在很多 UI 库也内置了骨架屏组件，用起来更方便，比如 Element UI、Ant Design 都有相关组件可以直接用。

## 答案 3：技术深度解析

### 1. 骨架屏的核心原理

骨架屏（Skeleton Screen）是在页面加载过程中，用灰色块和线条组成的简化版页面布局，模拟最终页面结构，减少用户等待感知的技术。其核心原理是：



*   在 HTML 加载早期就渲染简化版布局

*   与最终页面结构保持一致，减少布局偏移

*   通过动画效果提示用户内容正在加载

*   内容加载完成后平滑替换骨架屏

### 2. 实现方式及代码示例

#### 2.1 手动实现基础骨架屏

这是最直接的方式，适合简单页面，完全可控：



```

\<head>

&#x20; \<meta charset="UTF-8">

&#x20; \<meta name="viewport" content="width=device-width, initial-scale=1.0">

&#x20; \<style>

&#x20;   /\* 骨架屏基础样式 \*/

&#x20;   .skeleton {

&#x20;     background: #fff;

&#x20;     overflow: hidden;

&#x20;   }

&#x20;  &#x20;

&#x20;   /\* 骨架屏元素基础样式 \*/

&#x20;   .skeleton-item {

&#x20;     background: #f2f2f2;

&#x20;     border-radius: 4px;

&#x20;     animation: skeleton-loading 1.5s linear infinite;

&#x20;   }

&#x20;  &#x20;

&#x20;   /\* 加载动画 \*/

&#x20;   @keyframes skeleton-loading {

&#x20;     0% {

&#x20;       background-position: -200% 0;

&#x20;     }

&#x20;     100% {

&#x20;       background-position: 200% 0;

&#x20;     }

&#x20;   }

&#x20;  &#x20;

&#x20;   /\* 为骨架屏元素添加渐变效果，增强加载感 \*/

&#x20;   .skeleton-gradient {

&#x20;     background: linear-gradient(

&#x20;       90deg,

&#x20;       \#f0f0f0 25%,

&#x20;       \#e0e0e0 50%,

&#x20;       \#f0f0f0 75%

&#x20;     );

&#x20;     background-size: 200% 100%;

&#x20;   }

&#x20;  &#x20;

&#x20;   /\* 页面布局样式 \*/

&#x20;   .header {

&#x20;     padding: 16px;

&#x20;     border-bottom: 1px solid #eee;

&#x20;   }

&#x20;  &#x20;

&#x20;   .content {

&#x20;     padding: 16px;

&#x20;   }

&#x20;  &#x20;

&#x20;   .article-title {

&#x20;     height: 24px;

&#x20;   }

&#x20;   }

&#x20;  &#x20;

&#x20;   .article-image {

&#x20;     height: 200px;

&#x20;     width: 100%;

&#x20;     margin-bottom: 16px;

&#x20;   }

&#x20;  &#x20;

&#x20;   /\* 真实内容默认隐藏 \*/

&#x20;   .real-content {

&#x20;     display: none;

&#x20;   }

&#x20; \</style>

\</head>

\<body>

&#x20; \<!-- 骨架屏 -->

&#x20; \<div class="skeleton" id="skeleton">

&#x20;   \<div class="header">

&#x20;     \<div class="skeleton-item skeleton-gradient article-title">\</div>

&#x20;   \</div>

&#x20;   \<div class="content">

&#x20; \</div>

&#x20;&#x20;

&#x20; \<!-- 真实内容 -->

&#x20; \<div class="real-content" id="realContent">

&#x20;   \<div class="header">

&#x20;     \<h1>这是文章标题\</h1>

&#x20;   \</div>

&#x20;   \<div class="content">

&#x20;     \<img src="https://picsum.photos/800/400" alt="示例图片">

&#x20;     \<p>这是第一段文字内容，包含了文章的基本介绍和概述。\</p>

&#x20;     \<p>这是第二段文字内容，详细描述了相关的细节和信息。\</p>
```

#### 2.2 使用 Webpack 插件自动生成

对于复杂项目，推荐使用`vue-skeleton-webpack-plugin`（Vue 项目）或`react-skeleton-loader`（React 项目）等工具：

**Vue 项目配置示例：**



1.  安装依赖：



```
npm install vue-skeleton-webpack-plugin --save-dev
```



1.  创建骨架屏组件 `src/Skeleton.vue`：



```
\<template>

&#x20; \<div class="skeleton-wrapper">

&#x20;   \<!-- 骨架屏内容 -->

&#x20;   \<div class="skeleton-header">

&#x20;     \<div class="skeleton-avatar">\</div>

&#x20;     \<div class="skeleton-title">\</div>

&#x20;   \</div>

&#x20;   \<div class="skeleton-content">

&#x20;     \<div class="skeleton-block">\</div>

&#x20;     \<div class="skeleton-block">\</div>

&#x20;     \<div class="skeleton-block">\</div>

&#x20;   \</div>

&#x20; \</div>

\</template>

\<style scoped>

/\* 骨架屏样式 \*/

.skeleton-wrapper {

&#x20; padding: 16px;

}

.skeleton-header {

&#x20; display: flex;

&#x20; align-items: center;

&#x20; margin-bottom: 16px;

}

.skeleton-avatar {

&#x20; width: 40px;

&#x20; height: 40px;

&#x20; border-radius: 50%;

&#x20; background: #f2f2f2;

&#x20; margin-right: 12px;

}

.skeleton-title {

&#x20; flex: 1;

&#x20; height: 20px;

&#x20; background: #f2f2f2;

&#x20; border-radius: 4px;

}

.skeleton-content {

&#x20; width: 100%;

}

.skeleton-block {

&#x20; height: 16px;

&#x20; background: #f2f2f2;

&#x20; border-radius: 4px;

&#x20; margin-bottom: 8px;

}

/\* 动画效果 \*/

.skeleton-avatar, .skeleton-title, .skeleton-block {

&#x20; animation: skeleton-loading 1.5s linear infinite;

&#x20; background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);

&#x20; background-size: 200% 100%;

}

@keyframes skeleton-loading {

&#x20; 0% { background-position: -200% 0; }

&#x20; 100% { background-position: 200% 0; }

}

\</style>
```



1.  配置 Webpack（`vue.config.js`）：



```
const SkeletonWebpackPlugin = require('vue-skeleton-webpack-plugin');

const path = require('path');

module.exports = {

&#x20; configureWebpack: {

&#x20;   plugins: \[

&#x20;     new SkeletonWebpackPlugin({

&#x20;       // 骨架屏组件路径

&#x20;       webpackConfig: {

&#x20;         entry: {

&#x20;           app: path.join(\_\_dirname, './src/Skeleton.js'),

&#x20;         },

&#x20;       },

&#x20;       // 不同路由使用不同骨架屏

&#x20;       router: {

&#x20;         mode: 'history',

&#x20;         routes: \[

&#x20;           {

&#x20;             path: '/',

&#x20;             skeletonId: 'skeleton-home'

&#x20;           },

&#x20;           {

&#x20;             path: '/about',

&#x20;             skeletonId: 'skeleton-about'

&#x20;           }

&#x20;         ]

&#x20;       }

&#x20;     })

&#x20;   ]

&#x20; }

};
```



1.  创建入口文件 `src/Skeleton.js`：



```
import Vue from 'vue';

import Skeleton from './Skeleton.vue';

export default new Vue({

&#x20; components: {

&#x20;   Skeleton

&#x20; },

```

#### 2.3 使用 UI 库内置组件

现代 UI 库大多提供了骨架屏组件，如 Element UI 的`el-skeleton`：



```

&#x20;     \<img src="https://picsum.photos/800/400" alt="示例图片">

&#x20;     \<p>这是实际内容，当数据加载完成后显示\</p>

&#x20;   \</div>

&#x20; \</div>

\</template>

\<script>

export default {

&#x20; data() {

&#x20;   return {

&#x20;     loading: true // 控制骨架屏显示

&#x20;   };

&#x20; },

&#x20; mounted() {

&#x20;   // 模拟数据加载

&#x20;   setTimeout(() => {

&#x20;     this.loading = false; // 数据加载完成，隐藏骨架屏

&#x20;   }, 2000);

&#x20; }

};

\</script>
```

### 3. 骨架屏优化策略

#### 3.1 性能优化



*   **内联 CSS**：将骨架屏样式内联到 HTML 头部，避免额外的 CSS 请求

*   **简化结构**：只保留关键视觉元素，减少 DOM 节点数量

*   **使用 CSS 动画**：相比 JS 动画更高效，避免主线程阻塞

*   **适当压缩**：移除不必要的空格和注释，减小骨架屏代码体积

#### 3.2 用户体验优化



*   **保持布局一致**：骨架屏与最终页面的布局和元素位置应尽量一致

*   **添加微妙动画**：轻微的渐变或闪烁效果提示用户内容正在加载

*   **合理的显示时机**：内容加载完成后立即替换，避免不必要的延迟

*   **适配响应式**：确保骨架屏在不同设备上都能正确显示

### 4. 骨架屏 vs 其他加载状态方案



| 方案         | 优点           | 缺点         | 适用场景        |
| ---------- | ------------ | ---------- | ----------- |
| 骨架屏        | 视觉过渡自然，用户感知好 | 实现成本较高     | 内容布局固定的页面   |
| 加载 spinner | 实现简单，通用性强    | 无内容预览，等待感强 | 简单交互或弹窗加载   |
| 模糊占位图      | 过渡平滑，有内容暗示   | 需要提前知道图片尺寸 | 图片为主的页面     |
| 渐进式加载      | 先加载低质量内容     | 实现复杂       | 对加载体验要求高的场景 |

### 5. 总结

骨架屏是提升首屏加载体验的有效手段，实现方式从简单到复杂可分为：手动编写基础骨架屏、使用构建工具自动生成、利用 UI 库内置组件。选择哪种方式取决于项目复杂度和团队技术栈。

核心要点是：骨架屏应与最终页面布局一致，加载动画应简洁不抢眼，显示和隐藏时机要恰当。良好的骨架屏实现可以显著降低用户的等待焦虑，提升整体产品体验。

在实际开发中，还需结合懒加载、资源预加载等技术，形成完整的前端性能优化方案。
