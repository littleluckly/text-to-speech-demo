## 答案 1：核心简洁的口语化回答

・用一个对象作为缓存容器，存储函数参数与计算结果的映射

・调用函数时先检查缓存，存在对应参数的结果则直接返回，避免重复计算

・首次调用或参数未命中缓存时，执行原函数计算，将结果存入缓存后返回

・需处理参数序列化，确保不同形式的相同参数能命中同一缓存（如数组、对象参数）

・可扩展支持缓存过期、缓存大小限制等功能

## 答案 2：口语化扩展回答

带缓存的函数主要用来优化那些计算量大或者调用频繁的函数，比如复杂的数学计算、重复请求相同数据的操作。核心思路就是把之前算过的结果存起来，下次用一样的参数调用时，直接拿存好的结果，不用再重新计算。

实现的时候，通常会用一个内部对象当缓存库，键是函数的参数，值是对应的计算结果。调用函数前先看看参数在缓存里有没有记录，有的话直接返回值；没有的话就正常执行函数，算完之后把参数和结果存到缓存里，方便下次用。

不过这里有个关键点，就是参数怎么当键。如果参数是简单的数字、字符串还好，直接用就行。但如果是对象或者数组，就不能直接当键了，得转成字符串，比如用 JSON.stringify ()，这样才能保证相同内容的对象参数能命中同一个缓存。另外，还可以根据需要加一些功能，比如限制缓存的大小，防止存太多东西占内存，或者给缓存设置过期时间，避免数据太旧。

这种带缓存的函数在实际开发中很有用，比如处理用户频繁切换的筛选条件计算，或者缓存接口返回的相同数据，能明显提高性能，减少等待时间。

## 答案 3：技术深度解析

### 实现原理

带缓存功能的函数（也称为 "记忆化函数"）基于**空间换时间**的优化思想，通过存储函数的输入参数与输出结果的映射关系，避免对相同参数进行重复计算。其核心机制包括：



1.  缓存容器：用于存储参数与结果的映射（通常为对象或 Map）

2.  参数序列化：将输入参数转换为可作为缓存键的字符串

3.  缓存命中判断：调用时先检查参数是否已存在于缓存中

4.  缓存更新策略：首次计算后将结果存入缓存

### 基础版实现



```
/\*\*

&#x20;\* 创建带缓存功能的函数

&#x20;\* @param {Function} fn - 需要添加缓存的原函数

&#x20;\* @returns {Function} 带缓存的函数

&#x20;\*/

function withCache(fn) {

&#x20; // 用对象作为缓存容器，键为序列化后的参数，值为函数计算结果

&#x20; const cache = {};

&#x20;&#x20;

&#x20; // 返回一个新函数，该函数会先检查缓存

&#x20; return function(...args) {

&#x20;   // 1. 参数序列化：将参数数组转换为字符串作为缓存键

&#x20;   // 使用JSON.stringify可以处理数组、对象等复杂参数

&#x20;   const key = JSON.stringify(args);

&#x20;  &#x20;

&#x20;   // 2. 检查缓存：如果命中则直接返回缓存结果

&#x20;   if (cache.hasOwnProperty(key)) {

&#x20;     console.log(\`缓存命中：参数 \${key}\`);

&#x20;     return cache\[key];

&#x20;   }

&#x20;  &#x20;

&#x20;   // 3. 未命中缓存：执行原函数计算结果

&#x20;   console.log(\`缓存未命中：参数 \${key}，执行计算\`);

&#x20;   const result = fn.apply(this, args); // 保持原函数的this上下文

&#x20;  &#x20;

&#x20;   // 4. 更新缓存：将计算结果存入缓存

&#x20;   cache\[key] = result;

&#x20;  &#x20;

&#x20;   // 5. 返回计算结果

&#x20;   return result;

&#x20; };

}
```

### 进阶版实现（带缓存管理功能）

基础版仅实现了核心缓存功能，实际应用中还需要考虑缓存过期、缓存大小限制等问题，以下是增强版实现：



```
/\*\*

&#x20;\* 创建带高级缓存功能的函数

&#x20;\* @param {Function} fn - 需要添加缓存的原函数

&#x20;\* @param {Object} options - 缓存配置

&#x20;\* @param {number} \[options.maxSize=Infinity] - 最大缓存数量

&#x20;\* @param {number} \[options.maxAge=Infinity] - 缓存过期时间（毫秒）

&#x20;\* @param {Function} \[options.serializer=JSON.stringify] - 参数序列化函数

&#x20;\* @returns {Function} 带高级缓存的函数

&#x20;\*/

function advancedWithCache(fn, options = {}) {

&#x20; // 解析配置参数，设置默认值

&#x20; const {

&#x20;   maxSize = Infinity,

&#x20;   maxAge = Infinity,

&#x20;   serializer = JSON.stringify

&#x20; } = options;

&#x20;&#x20;

&#x20; // 缓存容器：存储结构为 { 键: { value: 结果, timestamp: 时间戳 } }

&#x20; const cache = new Map();

&#x20;&#x20;

&#x20; // 清理过期缓存的方法

&#x20; function cleanExpiredCache() {

&#x20;   const now = Date.now();

&#x20;   // 遍历缓存，删除过期条目

&#x20;   for (const \[key, entry] of cache.entries()) {

&#x20;     if (now - entry.timestamp > maxAge) {

&#x20;       cache.delete(key);

&#x20;       console.log(\`缓存过期：\${key}\`);

&#x20;     }

&#x20;   }

&#x20; }

&#x20;&#x20;

&#x20; // 清理超出容量的缓存（使用LRU策略：最近最少使用）

&#x20; function cleanExcessCache() {

&#x20;   if (cache.size <= maxSize) return;

&#x20;  &#x20;

&#x20;   // 获取缓存条目并按访问时间排序（最早访问的在前）

&#x20;   const sortedEntries = Array.from(cache.entries()).sort(

&#x20;     (\[, a], \[, b]) => a.timestamp - b.timestamp

&#x20;   );

&#x20;  &#x20;

&#x20;   // 计算需要删除的数量

&#x20;   const needToDelete = cache.size - maxSize;

&#x20;  &#x20;

&#x20;   // 删除最早访问的条目

&#x20;   for (let i = 0; i < needToDelete; i++) {

&#x20;     const \[key] = sortedEntries\[i];

&#x20;     cache.delete(key);

&#x20;     console.log(\`缓存溢出，删除最早条目：\${key}\`);

&#x20;   }

&#x20; }

&#x20;&#x20;

&#x20; // 缓存函数本体

&#x20; const cachedFn = function(...args) {

&#x20;   // 1. 清理过期缓存

&#x20;   cleanExpiredCache();

&#x20;  &#x20;

&#x20;   // 2. 序列化参数生成缓存键

&#x20;   const key = serializer(args);

&#x20;  &#x20;

&#x20;   // 3. 检查缓存是否命中

&#x20;   if (cache.has(key)) {

&#x20;     const entry = cache.get(key);

&#x20;     // 更新访问时间（用于LRU策略）

&#x20;     entry.timestamp = Date.now();

&#x20;     console.log(\`缓存命中：\${key}\`);

&#x20;     return entry.value;

&#x20;   }

&#x20;  &#x20;

&#x20;   // 4. 未命中缓存，执行原函数计算

&#x20;   console.log(\`缓存未命中：\${key}，执行计算\`);

&#x20;   const result = fn.apply(this, args);

&#x20;  &#x20;

&#x20;   // 5. 清理超出容量的缓存

&#x20;   cleanExcessCache();

&#x20;  &#x20;

&#x20;   // 6. 存入新缓存，记录当前时间戳

&#x20;   cache.set(key, {

&#x20;     value: result,

&#x20;     timestamp: Date.now()

&#x20;   });

&#x20;  &#x20;

&#x20;   // 7. 返回计算结果

&#x20;   return result;

&#x20; };

&#x20;&#x20;

&#x20; // 为缓存函数添加手动管理方法

&#x20; cachedFn.clearCache = () => {

&#x20;   cache.clear();

&#x20;   console.log('缓存已清空');

&#x20; };

&#x20;&#x20;

&#x20; cachedFn.getCacheSize = () => cache.size;

&#x20;&#x20;

&#x20; return cachedFn;

}
```

### 关键技术点解析



1.  **参数序列化策略**



```
// 自定义序列化函数示例（忽略函数参数）

function customSerializer(args) {

&#x20; return JSON.stringify(args.map(arg =>&#x20;

&#x20;   typeof arg === 'function' ? '\[Function]' : arg

&#x20; ));

}
```



*   简单类型（字符串、数字）：可直接作为键

*   复杂类型（对象、数组）：需序列化为字符串（如 JSON.stringify）

*   特殊场景：可自定义序列化函数处理函数参数或循环引用对象

1.  **缓存淘汰策略**

*   LRU（Least Recently Used）：淘汰最近最少使用的缓存（进阶版采用）

*   FIFO（First In First Out）：淘汰最早进入的缓存

*   LFU（Least Frequently Used）：淘汰使用频率最低的缓存

*   过期时间：基于时间的淘汰策略

1.  **缓存容器选择**

*   Object：简单场景使用，键只能是字符串

*   Map：更适合缓存场景，支持任意类型作为键，且有内置迭代方法

*   WeakMap：适合键为对象且需要自动回收的场景（当对象被销毁时自动删除缓存）

1.  **与原函数的兼容性**

*   使用`apply`保持原函数的`this`上下文

*   通过剩余参数`...args`支持任意数量的参数

*   对异步函数（返回 Promise）同样适用

### 适用场景与注意事项

#### 适用场景



*   计算密集型函数（如数学计算、数据转换）

*   频繁调用且参数重复度高的函数

*   网络请求（缓存接口返回结果）

*   配置解析、模板编译等一次性计算多次使用的场景

#### 注意事项



*   避免对副作用函数使用缓存（如修改全局变量、操作 DOM 的函数）

*   注意缓存键的唯一性，避免不同参数序列化后得到相同键

*   缓存会占用内存，需根据实际情况设置合理的缓存大小和过期时间

*   对于结果会随时间变化的函数（如获取实时数据），必须设置过期时间

### 总结

实现带缓存功能的函数核心在于建立参数与结果的映射关系，并通过合理的缓存策略管理这些映射。基础版实现简单，适用于参数简单、计算稳定的场景；进阶版通过添加缓存过期、容量限制等功能，更适合生产环境使用。

在实际开发中，记忆化缓存是一种简单有效的性能优化手段，尤其适合处理重复计算或重复请求的场景。但需注意缓存的维护成本和内存占用，避免过度缓存导致的问题。
