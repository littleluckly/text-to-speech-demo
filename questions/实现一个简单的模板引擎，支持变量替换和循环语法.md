## 答案 1：核心简洁的口语化回答

・变量替换通过识别`{{变量名}}`格式，用数据中对应的值替换，支持点语法（如`{{user.name}}`）

・循环语法使用`{{#each 数组名}}`作为开始标签，`{{/each}}`作为结束标签，遍历数组生成重复内容

・实现时先解析模板，区分普通文本、变量标签和循环块

・循环块处理需递归渲染每个数组元素对应的子模板

・整体流程：先处理循环结构（因可能嵌套变量），再处理变量替换，最终拼接成结果字符串

## 答案 2：口语化扩展回答

简单模板引擎的核心是把数据和模板结合生成最终内容，主要处理两种语法。变量替换就是把模板里`{{}}`包着的内容换成数据里对应的值，比如模板写`{{title}}`，数据有`title: "Hello"`，就会换成 Hello，遇到`{{user.age}}`这种带点的，就去数据的 user 对象里找 age。

循环的话，用`{{#each list}}`和`{{/each}}`包裹要重复的内容，比如遍历商品列表，模板里这对标签中间的内容会根据 list 数组的每个元素重复生成。每个元素里的变量，比如`{{name}}`，会对应到数组元素的 name 属性。

实现时，先找模板里的循环块，把循环块里的子模板取出来，遍历对应的数组，把每个元素的数据放进子模板里渲染，再把结果拼起来替换掉循环块。之后再处理所有的变量替换，把剩下的`{{变量}}`都换成对应的值。这样即使循环里面嵌套变量，或者循环里面再嵌套循环，都能处理，最终得到完整的渲染结果。

## 答案 3：技术深度解析

### 整体设计思路

一个简单的模板引擎主要由**解析器**和**渲染器**两部分组成。解析器负责识别模板中的特殊语法标签（变量和循环），渲染器负责将数据填充到模板中。本实现采用 "先处理循环，再处理变量" 的策略，因为循环块内部可能包含变量或嵌套循环。

支持的语法规则：



*   变量替换：`{{variable}}` 或 `{{obj.prop}}`（支持点语法访问嵌套属性）

*   循环语法：`{{#each array}}` 开始标签和 `{{/each}}` 结束标签，内部可使用数组元素的属性

### 完整实现代码



```
class SimpleTemplateEngine {

&#x20; /\*\*

&#x20;  \* 渲染模板

&#x20;  \* @param {string} template - 模板字符串

&#x20;  \* @param {Object} data - 数据对象

&#x20;  \* @returns {string} 渲染后的字符串

&#x20;  \*/

&#x20; render(template, data) {

&#x20;   // 先处理循环（循环中可能包含变量或嵌套循环）

&#x20;   let processed = this.processEachBlocks(template, data);

&#x20;   // 再处理所有变量替换

&#x20;   processed = this.processVariables(processed, data);

&#x20;   return processed;

&#x20; }

&#x20; /\*\*

&#x20;  \* 处理模板中的所有循环块

&#x20;  \* @param {string} template - 模板字符串

&#x20;  \* @param {Object} data - 数据对象

&#x20;  \* @returns {string} 处理完循环后的字符串

&#x20;  \*/

&#x20; processEachBlocks(template, data) {

&#x20;   // 正则匹配循环块：{{#each 数组名}}...{{/each}}

&#x20;   // 正则说明：

&#x20;   // {{#each\s+(\w+)\s\*}} 匹配开始标签并捕获数组名

&#x20;   // (\[\s\S]\*?) 非贪婪匹配捕获循环体内容（包括换行符）

&#x20;   // {{/each}} 匹配结束标签

&#x20;   const eachRegex = /{{#each\s+(\w+)\s\*}}(\[\s\S]\*?){{\\/each}}/g;

&#x20;   // 替换所有循环块

&#x20;   return template.replace(eachRegex, (match, arrayName, blockTemplate) => {

&#x20;     // 获取循环对应的数组数据

&#x20;     const arrayData = this.getNestedValue(data, arrayName);

&#x20;    &#x20;

&#x20;     // 非数组类型直接返回空（容错处理）

&#x20;     if (!Array.isArray(arrayData)) {

&#x20;       return '';

&#x20;     }

&#x20;     // 遍历数组，渲染每个元素对应的子模板

&#x20;     const renderedItems = arrayData.map(item => {

&#x20;       // 递归处理子模板（支持嵌套循环）

&#x20;       // 1. 先处理子模板中的循环

&#x20;       let processedBlock = this.processEachBlocks(blockTemplate, item);

&#x20;       // 2. 再处理子模板中的变量

&#x20;       processedBlock = this.processVariables(processedBlock, item);

&#x20;       return processedBlock;

&#x20;     });

&#x20;     // 拼接所有渲染结果，替换整个循环块

&#x20;     return renderedItems.join('');

&#x20;   });

&#x20; }

&#x20; /\*\*

&#x20;  \* 处理模板中的所有变量替换

&#x20;  \* @param {string} template - 模板字符串

&#x20;  \* @param {Object} data - 数据对象

&#x20;  \* @returns {string} 处理完变量后的字符串

&#x20;  \*/

&#x20; processVariables(template, data) {

&#x20;   // 正则匹配变量：{{变量名}} 或 {{obj.prop}}

&#x20;   // 支持空格：{{  variable  }} 或 {{  obj.prop  }}

&#x20;   const variableRegex = /{{\s\*(\[a-zA-Z0-9\_.]+)\s\*}}/g;

&#x20;   // 替换所有变量

&#x20;   return template.replace(variableRegex, (match, variablePath) => {

&#x20;     // 获取变量路径对应的值（支持点语法）

&#x20;     const value = this.getNestedValue(data, variablePath);

&#x20;     // 未找到对应值时返回空字符串（容错处理）

&#x20;     return value !== undefined ? value : '';

&#x20;   });

&#x20; }

&#x20; /\*\*

&#x20;  \* 根据路径获取嵌套对象的值（支持点语法）

&#x20;  \* @param {Object} data - 数据对象

&#x20;  \* @param {string} path - 属性路径，如 "user.name" 或 "age"

&#x20;  \* @returns {\*} 路径对应的属性值，未找到则返回undefined

&#x20;  \*/

&#x20; getNestedValue(data, path) {

&#x20;   // 将路径拆分为数组，如 "user.name" 拆分为 \["user", "name"]

&#x20;   const pathSegments = path.split('.');

&#x20;  &#x20;

&#x20;   // 递归查找嵌套属性

&#x20;   let current = data;

&#x20;   for (const segment of pathSegments) {

&#x20;     // 如果当前不是对象或找不到属性，返回undefined

&#x20;     if (current === null || typeof current !== 'object' || !(segment in current)) {

&#x20;       return undefined;

&#x20;     }

&#x20;     current = current\[segment];

&#x20;   }

&#x20;   return current;

&#x20; }

}
```

### 核心功能解析

#### 1. 嵌套属性访问（getNestedValue 方法）

该方法是实现变量替换的核心，支持通过点语法访问嵌套属性：



```
// 示例：

const data = {

&#x20; user: {

&#x20;   name: "Alice",

&#x20;   address: {

&#x20;     city: "Beijing"

&#x20;   }

&#x20; }

getNestedValue(data, "user.name"); // 返回 "Alice"

getNestedValue(data, "user.address.city"); // 返回 "Beijing"

getNestedValue(data, "user.age"); // 返回 undefined（属性不存在）
```

**实现原理**：



*   将属性路径按`.`分割成片段数组

*   从数据对象根部开始，依次访问每个片段对应的属性

*   若中间任何一步无法访问（如属性不存在），则返回`undefined`

#### 2. 变量替换（processVariables 方法）

通过正则表达式匹配`{{variable}}`格式的变量标签，并替换为对应的值：

**正则解析**：`/{{\s*([a-zA-Z0-9_.]+)\s*}}/g`



*   `{{\s*`：匹配`{{`开头，允许中间有任意空格

*   `([a-zA-Z0-9_.]+)`：捕获变量名（支持字母、数字、下划线和点）

*   `\s*}}`：匹配`}}`结尾，允许中间有任意空格

*   `g`：全局匹配，替换所有变量

**处理流程**：



1.  用正则匹配所有变量标签

2.  对每个匹配项，调用`getNestedValue`获取对应值

3.  用获取到的值替换变量标签

4.  未找到对应值时，用空字符串替换（容错处理）

#### 3. 循环处理（processEachBlocks 方法）

循环处理是最复杂的部分，需要识别循环块并递归渲染每个元素：

**正则解析**：`/{{#each\s+(\w+)\s*}}([\s\S]*?){{\/each}}/g`



*   `{{#each\s+(\w+)\s*}}`：匹配循环开始标签，捕获数组名

*   `([\s\S]*?)`：非贪婪匹配，捕获循环体内容（`[\s\S]`匹配包括换行符在内的所有字符）

*   `{{\/each}}`：匹配循环结束标签

**处理流程**：



1.  用正则匹配所有循环块

2.  对每个循环块，获取对应的数组数据

3.  遍历数组，对每个元素执行：

*   递归处理子模板中的循环（支持嵌套循环）

*   处理子模板中的变量

1.  拼接所有元素的渲染结果，替换整个循环块

### 使用示例



```
// 1. 创建模板引擎实例

const engine = new SimpleTemplateEngine();

// 2. 定义模板

const template = \`

&#x20; \<h1>{{title}}\</h1>

&#x20; \<ul>

&#x20;   {{#each users}}

&#x20;     \<li>

&#x20;       \<span>{{name}}\</span>

&#x20;       \<span>Age: {{age}}\</span>

&#x20;       \<div>Hobbies:

&#x20;         \<ul>

&#x20;           {{#each hobbies}}

&#x20;             \<li>{{.}}\</li> \<!-- 用{{.}}访问数组元素本身 -->

&#x20;           {{/each}}

&#x20;         \</ul>

&#x20;       \</div>

&#x20;     \</li>

&#x20;   {{/each}}

&#x20; \</ul>

\`;

// 3. 定义数据

const data = {

&#x20; title: "User List",

&#x20; users: \[

&#x20;   {

&#x20;     name: "Alice",

&#x20;     age: 25,

&#x20;     hobbies: \["reading", "swimming"]

&#x20;   },

&#x20;   {

&#x20;     name: "Bob",

&#x20;     age: 30,

&#x20;     hobbies: \["coding", "hiking", "gaming"]

&#x20;   }

&#x20; ]

};

// 4. 渲染模板

const result = engine.render(template, data);

console.log(result);
```

### 扩展与优化方向



1.  **增加条件判断语法**：支持`{{#if condition}}...{{/if}}`和`{{#else}}`语法，处理条件渲染场景。

2.  **提高性能**：

*   增加模板编译阶段，将模板解析为函数（类似 Vue 模板编译），避免重复解析

*   使用缓存机制，缓存已编译的模板

1.  **增强容错能力**：

*   增加模板语法错误提示

*   处理循环数据为 null/undefined 的情况

*   允许设置变量默认值（如`{{user.name || 'Guest'}}`）

1.  **支持更多语法特性**：

*   数组索引访问（如`{{users.0.name}}`）

*   过滤器（如`{{date | format}}`）

*   模板继承与片段（类似 Handlebars 的 partial）
